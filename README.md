# S2029_ACTAR
Directory format based on https://github.com/loopset/e796-analysis and https://github.com/ibc12/S2384 for ACTAR TPC analysis by MLG and IBC.
Analysis by AT for experiment S2029 with ACTAR TPC at TRIUMF for the measurement of the 2 proton and alpha channels from the decay of the 6.15 MeV state of 18Ne. Analysis notes found in https://docs.google.com/document/d/1awkXm4EUb6oerAJpO0dmrP9tCfUWv1ngwFJigcCKq7A/edit?usp=sharing.
